# 업무 캘린더

폰과 개인 노트북에서 같이 쓰는 업무 캘린더 + 체크리스트 앱 (PWA).
일정은 기기에서 종단간 암호화한 뒤 동기화된다.

## 기능

- **오늘 할 일** (열면 바로 보이는 화면): 오늘 일정, 완료 수, 밀린 업무, 진행률, 다가오는 7일
- **주간 / 월별**: 날짜별 일정과 완료 현황, 날짜를 눌러 바로 추가
- **업무 체크리스트 + 준비물 체크리스트**: 모두 체크하면 자동 완료
- **반복 업무 템플릿**: 예) "입찰"을 고르면 업무 단계와 준비 서류가 자동으로 채워짐
- **반복 일정**: 매주 / 매월 N회
- **기기 간 동기화**: 종단간 암호화 (아래 참고)
- **오프라인 동작**, 홈 화면에 설치 가능, 백업 내보내기 / 가져오기

## 설치 (처음 한 번)

### 1. Supabase 만들기 (무료)

1. https://supabase.com 가입 → New project (Region: Northeast Asia (Seoul) 권장)
2. 왼쪽 **SQL Editor** → `supabase.sql` 내용을 붙여 넣고 **Run**
3. **Project Settings → API**에서 *Project URL*과 공개 키(*anon* 또는 *publishable*)를 복사
   - `service_role` / `secret` 키는 절대 쓰지 말 것

### 2. 배포 (GitHub Pages)

이 저장소 → **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main** / **(root)** → Save.
1~2분 뒤 `https://jayfwng.github.io/work_calendar/` 에서 열린다.

저장소에는 앱 코드만 있고 일정 데이터는 올라가지 않는다.
`config.js`는 비워 두고 Supabase URL·공개 키는 각 기기 앱 설정 화면에서 입력한다.

### 3. 기기 연결

1. **노트북**: `https://jayfwng.github.io/work_calendar/` 열기 → 설정 → 기기 간 동기화 → **새로 시작** → 동기화 키(25자) 확인
2. **폰**: 같은 주소 열기 → 공유 버튼 → **홈 화면에 추가** (안드로이드는 메뉴 → 앱 설치)
3. 폰 앱 → 설정 → **키로 연결**에 노트북의 키 입력

이후엔 수정할 때마다, 앱을 열 때마다, 열려 있는 동안 1분마다 자동으로 동기화된다.

> 예전에 `index.html` 파일을 직접 열어 쓰던 데이터는 주소가 달라서 자동으로 넘어오지 않는다.
> 예전 화면에서 **백업 내보내기** → 새 주소에서 **백업 가져오기**.

## 암호화 방식

- 동기화 키: 기기에서 만든 25자 난수(약 125비트). **서버로 보내지 않는다.**
- 키에서 HKDF-SHA256으로 ① AES-256-GCM 암호화 키 ② 저장소 ID를 만든다.
- 서버(Supabase)에는 `저장소 ID / 암호문 / 버전`만 저장되어 서버 운영자도 내용을 볼 수 없다.
- 테이블은 직접 읽거나 목록을 볼 수 없고, 저장소 ID를 아는 경우에만 함수로 읽고 쓸 수 있다.
- 키를 잃어버리면 서버 데이터는 복구할 수 없다(각 기기 데이터는 남아 있음).
- 두 기기에서 따로 고쳐도 일정 단위로 병합된다(나중에 수정한 쪽 우선, 삭제도 반영).

## 주의

- **개인 기기(폰, 개인 노트북) 전용으로 쓰기.** 회사 PC에서는 동기화를 켜지 않는다.
- 암호화와 별개로, 업무 내용을 개인 기기에 적는 것도 회사 정책이 있을 수 있으니
  입찰가나 내부 기밀 수준의 정보는 넣지 않는 걸 권장.
